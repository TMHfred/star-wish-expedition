# 初期角色池：R／SR 製作規格

更新：本文件的十位角色已接入角色資料、戰鬥、獨立星盤與原創素材（2026-11-03）。以下原始設計與驗證目標保留供對照；不再代表僅有規格未實作。Q版目前為單張素材搭配程序動作。整體稀有度平衡仍需持續實測，尚未宣稱所有情境達到目標比例。

本次依作者確認名單製作十位角色的外觀、普攻、唯一必殺技及五個星盤關鍵節點。名稱、職業及戰鬥定位沿用作者設定；以下數值為待接入戰鬥驗證的第一版設計值。這份文件不代表十位角色已可出戰，也不將現有三位基礎測試角色直接改名替代。

初期共13位：R 6、SR 4、SSR 3。SSR 嘉妮特、卡蒂亞、米菈沿用現有資料。所有角色僅劍士／弓箭手／法師三職業，不增加副職業或額外主動技能。

## 共用計算與美術規格

- 攻擊係數以角色當前攻擊力計算；治療同樣使用攻擊力。必殺消耗100獨立能量，能量取得先沿用現有規則，不藉本文件變更。
- 射程以戰鬥格中心距離計算。圓形範圍標示半徑；近戰範圍以朝向目標的扇形計算。多段命中共享同次施法編號。
- 同名增益及控制不疊層，只刷新時間；減傷取最高值。不得復活或過量治療。必殺於死亡時取消剩餘段數。
- 控制基準：一般怪正常生效；首領免疫擊退及冰凍，但仍承受傷害與減速。首領標記與控制規則須在接入時實作，目前不假定引擎已支援。
- 立繪為精緻手繪奇幻人物；戰鬥為大頭短身Q版，保持武器與主色可辨識。特效採卡通手繪，禁止像素風。各角色需獨立立繪、Q版待機／移動／攻擊／必殺／受擊／死亡素材；本次不把文字規格當成已完成素材。

## R 角色

### 見習劍士 艾倫

- 外觀：栗色短髮青年，米白布衣、藍色短披肩及輕皮甲；單手鐵劍，輪廓簡潔。Q版保留藍披肩與劍尖亮點。
- 普攻「基礎斬擊」：對單一近身敵人造成100%傷害。
- 必殺「勇氣橫斬」：朝目標施展120度、距離1.5格的單次橫斬，每名敵人受到180%傷害。金白色短弧，定位為容易操作的近戰清群。
- 五個關鍵節點：①攻擊+2%；②生命+4%；③護甲減傷+1個百分點；④普攻傷害+3%；⑤勇氣橫斬傷害+4%。

### 鐵壁守衛 布魯諾

- 外觀：深棕短髮壯年守衛，灰鐵重甲與暗橙布帶；短劍及大型方盾。Q版以寬盾、低重心辨識。
- 普攻「守衛斬擊」：單體100%傷害，不額外嘲諷。
- 必殺「盾壁衝擊」：前方120度、距離1.3格造成140%傷害，將敵人向外擊退最多1格；自己減傷10%，持續3秒。阻擋格停止位移，不能推至地圖外。特效為土金色盾形衝擊。
- 五個關鍵節點：①攻擊+2%；②生命+4%；③護甲減傷+1個百分點；④普攻傷害+3%；⑤盾壁衝擊傷害+4%，不延長減傷或擊退。

### 森林獵手 莉芙

- 外觀：深綠短髮少女，森林綠斗篷、棕色皮革護腕；木製長弓與葉形箭羽。Q版保留綠兜帽與長弓。
- 普攻「獵手箭」：單體100%傷害，直線投射物，不穿透。
- 必殺「定點三連矢」：0.8秒內向施放時的單一目標射出三箭，每箭80%，總240%；目標死亡後剩餘箭取消，不自動轉火。綠色風線與葉片尾跡。
- 五個關鍵節點：①攻擊+2%；②生命+4%；③護甲減傷+1個百分點；④普攻傷害+3%；⑤三連矢各箭傷害+4%。

### 活力射手 菲恩

- 外觀：橘棕亂髮少年，黃白短外套與藍色腰包；輕巧短弓。Q版保留橘髮與亮黃袖口。

### 草藥少女 芙蘿拉

- 外觀：蜂蜜棕編髮少女，米白裙與鼠尾草綠圍裙；草藥包、花苞短杖。Q版保留側辮與圓形草藥包。
- 普攻「芽光彈」：對單一敵人造成100%魔法傷害，普攻不自動治療。

- 五個關鍵節點：①攻擊+2%；②生命+4%；③護甲減傷+1個百分點；④普攻傷害+3%；⑤草葉療癒治療量+4%。

## SR 角色

### 疾風雙刃 賽菈

- 外觀：銀灰高馬尾少女，青綠短披風與深色輕甲；一長一短雙刃。職業仍為劍士。Q版保留雙刃交叉輪廓。
- 普攻「交錯刃」：每次攻擊以兩段動畫呈現，各50%傷害；整次攻擊僅計一次能量取得，不能因兩段獲得雙倍能量。
- 必殺「疾風亂舞」：對單一近身目標，在1秒內斬擊四次，每次75%，總300%；目標死亡後停止，不轉火。青白交叉刀痕，不跨場瞬移。
- 五個關鍵節點：①攻擊+3%；②生命+7%；③護甲減傷+1.5個百分點；④疾風亂舞傷害+6%；⑤施法開始時目標生命低於40%，本次必殺傷害額外+5%。第四與第五節點增傷加算。

- 必殺「蒼雷連鎖」：第一目標160%，跳向距上一目標2格內的第二人100%、第三人70%；每人最多一次，總上限330%。以最近距離、再固定ID選取；無目標即結束。不暈眩。藍白折線閃電，最多三條命中表現。
- 五個關鍵節點：①攻擊+3%；②生命+7%；③護甲減傷+1.5個百分點；④蒼雷連鎖各段傷害+6%；⑤成功命中第三名不同敵人時，第三段額外+8%傷害。增傷加算，不新增跳躍。

### 冰晶魔女 艾莉絲

- 外觀：冰藍長髮女性，白藍層疊法袍與透明晶片飾物；菱形冰晶法杖。Q版保留冰晶杖尖與寬袖。
- 普攻「冰晶彈」：單體100%魔法傷害，不附帶常駐減速。

## 星盤與強度驗證基準

每位維持49節點、Lv.1至50；44顆一般節點及5顆關鍵節點。一般節點可一鍵培養，關鍵節點需手動。分支長度沿用8／9／9／9／9顆一般節點，每條末端一顆關鍵節點。

第一版統一使用18攻擊、18生命、8防禦一般節點：R每顆攻擊+1.4%、生命+2%、護甲減傷+0.3個百分點；SR每顆攻擊+1.7%、生命+2.5%、護甲減傷+0.4個百分點。增幅以初始能力加算，再乘關鍵節點加成。相較既有SSR每顆2%／3%／0.5個百分點，保留完整養成但降低成長幅度。暫沿用既有節點成本，共1370碎片，不另訂材料或稀有度折扣；不改變首通與放置收益。

目標為相同等級、突破與操作條件下，同職責整體效益SSR高於SR、SR高於R；不要求每個單項都嚴格排序，例如R守衛可有較高基礎生命。治療、控制和清群不能只比較面板攻擊。

接入後須以單體首領、三名聚集敵人、六名分散敵人及60秒持續戰鬥比較：有效傷害、有效治療、存活時間、控制時間與必殺頻率。SR同職責綜合效益以SSR約80%～90%、R以約65%～75%為初步目標，不能在未實測前宣稱達標；若超標優先調低係數或持續時間，保留角色特色。重複多位控制者也需測試，避免形成永久控制。

## 後續接入順序

1. 確認本版外觀與技能方向，製作獨立角色立繪與Q版素材。
2. 加入共用角色資料，以穩定ID保存；既有基礎測試角色與舊存檔安排明確遷移，不能默默替換。
3. 接入普攻／必殺及控制規則，測試後再開放編隊。
4. 將星盤存檔擴充為逐角色資料，保留嘉妮特現有進度，再接入十人星盤與平衡驗證。
5. 角色池及持有角色存檔完成後，再接抽選；不因本次文件自行設定抽卡機率、保底或初始角色。
