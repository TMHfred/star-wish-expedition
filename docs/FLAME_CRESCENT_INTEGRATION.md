# 嘉妮特火焰月牙特效：已確認樣板

使用者已確認這次特效可接受。2026-11-03 同步到 GitHub 供 Codex 整合。

## 檔案
- dist/assets/flame-crescent-preview.png：RGBA 透明火焰月牙原圖，1254×1254。
- dist/flame-crescent-preview.html / .css / .js：獨立動態預覽，沿用現有戰鬥引擎與三段攻擊時序。
- 預覽入口：/flame-crescent-preview.html；若在 GitHub Pages 專案子路徑下，使用相對入口。

## 正式整合方式
只把 `flame-crescent-preview.js` 裡的 `paintFlameCrescent(a,b,n,age)` 提取到正式渲染程式，載入上列素材，再從原 `slash()` 的 flame 分支呼叫。n=0、1、2 對應三刀。最後一刀視覺放大、火星較多。這是單張繪製素材搭配程式動畫，並非逐格精靈表。

保留既有 BattleRules 決定的攻擊時刻（0.25、0.5、0.8秒）、命中範圍、鎖定朝向、傷害、能量消耗與死亡取消規則。特效繪製不可另外產生傷害。

不要直接以整份預覽 JS 覆蓋正式 portrait.js：預覽含單人隊伍、所有測試單位 HP 設為10000、重播站位、播放後暫停、逐格檢視及背景切換，這些全部只屬於測試頁。

## 驗收
- 三刀方向／角度有差異，最後一刀加強，沒有黑底或方形邊界。
- 保留橘紅火焰、金黃亮核心、短殘影與散落火星，不新增地面光圈。
- 草地與深色背景皆可辨識；左右朝向與不同敵人方位均要測試。
- 目前動畫會以目標角度旋轉月牙，左右朝向需在正式整合時實機確認，不宣稱已有完整方向驗收。
- 五人交戰不過度遮擋角色；同一刀仍可對範圍內多名敵人命中。
- 測試手機效能與載入失敗處理。
- 執行 node --test tests/*.cjs。
